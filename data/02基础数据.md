# 基础数据

- 数据库中的时间统一采用美国东部标准时间（EST），使用 24 小时制。例如，`02:30:00` 表示美国东部标准时间凌晨 2 点 30 分。

## 用户

每位用户的资料包含以下信息。

- 唯一的用户 ID
- 电子邮箱
- 默认地址
- 支付方式

支付方式共有三类，分别是**礼品卡**、**PayPal 账户**和**信用卡**。

## 商品

本店共有 50 种商品。

每种**商品**都有不同**选项**组合对应的**规格项**。

例如，同一款 T 恤可以有蓝色 M 码和红色 L 码两种规格项。

每种商品包含以下属性。

- 唯一的商品 ID
- 商品名称
- 规格项列表

每个规格项包含以下属性。

- 唯一的规格项 ID
- 该规格项的选项值，例如颜色和尺码
- 供应状态
- 价格

商品 ID 和规格项 ID 是两套独立的编号，使用时请分别核对。

## 订单

每笔订单包含以下属性。

- 唯一的订单号
- 用户 ID
- 地址
- 所购商品明细
- 订单状态
- 发货信息，包括物流追踪编号和规格项 ID
- 支付记录

订单状态包括 **`pending`（待处理）**、**`processed`（已处理）**、**`delivered`（已签收）**和 **`cancelled`（已取消）**。

根据已经执行的操作，订单还可能包含取消原因、已换货的商品、换货差价等可选属性。
